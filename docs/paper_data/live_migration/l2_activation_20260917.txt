- pod-to-pod 통신 (node-b -> node-a): **실패** — Calico cross-subnet 문제 재현

  libvirt/neutron-ovs-agent/nova-compute 파드가 node-b에서 Init 단계에 정체, 진행 불가.

**여기서 중단.** 재개 절차에 명시된 대로, Calico Installation CR patch
(`ipPools[0].encapsulation: VXLAN`)는 사용자가 node-a SSM에서 직접 실행해야 함
(서브에이전트 범위 밖). patch 적용 후 이어서:
  1. neutron-ovs-agent/libvirt/nova-compute 파드가 node-b에서 자동으로 Init 통과하는지 확인
  2. `openstack compute service list`에 두 호스트 모두 nova-compute up 확인
  3. `nova-manage cell_v2 discover_hosts` 실행
  4. `openstack hypervisor list`에 하이퍼바이저 2개 up 확인
  5. (재개 절차에 따라 felixconfiguration vxlanPort 4790 patch도 L2 완료 "직후" 함께 적용 권장 —
     지난 세션에서 vxlanPort 미조정 시 L3 단계에서 neutron-ovs-agent가 나중에 다시
     Not Ready(VXLAN 4789 포트 충돌)로 막혔던 전례 있음)
